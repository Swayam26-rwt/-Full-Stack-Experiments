# 📖 Project Overview

This experiment implements a **Post Composer Module** capable of creating and managing social media posts across multiple platforms.

The application validates user input according to platform-specific rules, allows users to save and manage drafts, and simulates backend interactions using mock APIs.

The project demonstrates modern React development practices using reusable components, custom hooks, controlled forms, and modular architecture.

---

# 🎯 Objectives

- Build a reusable Post Composer
- Validate platform-specific character limits
- Manage post drafts efficiently
- Implement reusable React Hooks
- Apply Strategy Design Pattern
- Simulate backend API interactions
- Display loading and success states
- Improve user experience with notifications

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Swayam26-rwt/-Full-Stack-Experiments.git
```

Navigate to Experiment 1

```bash
cd Full-Stack-Experiments/Experiment\ 1
```

Install dependencies


Run the project

```bash

```
